Personal CV & Portfolio Website

This project consists of the design and development of a single-page website showcasing my Curriculum Vitae and professional portfolio for the Hypermedia course.

1. Project Analysis

User Profile (User Persona)

Name: Max Belfort (Tech Recruiter / Headhunter)

Age: 20 years old

Occupation: Talent Acquisition Specialist at a technology company.

Expectations: Wants to quickly review developer and designer profiles. Looking for professional experience, core skills, and links to previous projects in a clear, distraction-free layout.

Frustrations: Wasting time navigating overly complex websites, broken links, or lack of clarity regarding technical stacks.

Information Architecture

The information architecture of this single-page website has been structured linearly and hierarchically to allow recruiters and hiring managers to scan the professional profile in just a few seconds. At the top of the page, the header incorporates a fixed navigation bar with smooth-scroll anchor links, allowing users to jump directly to specific sections without losing spatial awareness.

The main content area begins with a Hero section combining a professional profile picture, a clear job title, and an executive summary. Next, the Work Experience section is organized in reverse chronological order using clear card components. Following this, the Education and Certifications section outlines the candidate's academic background.

To highlight practical skills, a Projects/Portfolio section is included, where each card displays the project name, applied technologies, and external links to code repositories or live pages. Finally, the Skills section organizes both technical and soft competencies using clean visual tags, culminating in an interactive footer with direct links to professional networks (LinkedIn, GitHub) and direct contact options.

Visual Design

The visual design follows a minimalist, professional, and accessible approach, adhering to high readability and web contrast standards. The color palette features a modern monochromatic scheme enriched with a vibrant accent color: a deep navy blue (#1e293b) for primary text and headings, a soft neutral gray (#f8fafc) for alternating section backgrounds to create visual rhythm, and an indigo blue (#4f46e5) reserved for buttons, links, and key interactive elements.

Regarding typography, Inter / System Sans-Serif has been chosen due to its exceptional legibility across various screen resolutions. Type scale and font weights (font-weight) clearly differentiate headings (h1, h2, h3) from body copy, establishing a robust visual hierarchy.

The layout is built using CSS Grid and Flexbox to guarantee fluid responsiveness across desktop, tablet, and mobile devices. Generous whitespace prevents visual fatigue, while subtle border radii and smooth button transition effects add a contemporary, polished feel to the overall user experience.
